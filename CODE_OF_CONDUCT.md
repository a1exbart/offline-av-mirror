# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be civil, assume competence, keep the discussion about the work.
Harassment of any kind is not tolerated.

Report unacceptable behaviour through a GitHub private vulnerability report or
by contacting the maintainer directly. Reports are handled confidentially.
